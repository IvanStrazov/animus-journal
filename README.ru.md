# claude-journal

**Минималистичный журнал проекта для Claude Code с жёстким бюджетом токенов.**

[English version](README.md)

Большинство плагинов памяти записывают всё подряд и расплачиваются контекстом. claude-journal устроен наоборот: короткий журнал, который удобно читать человеку, а расход держится низким за счёт лимитов, зашитых в код, а не только в промпт.

- **Снимок проекта ≤ 40 строк** (`STATE.md`) и 5 последних строк индекса подгружаются при старте сессии. И всё.
- **Запись о сессии ≤ 20 строк**, одним вызовом в конце работы.
- **Поиск по тегу задачи**: `find <тег>` возвращает только 3 последние подходящие записи, а не всю историю.
- **Никаких хуков на каждый вызов инструмента или сообщение.** Только один хук `SessionStart`.
- **Один Python-файл на стандартной библиотеке + обычный Markdown.** Без базы данных, векторного поиска, фоновых процессов, сети и дополнительных вызовов модели.

## Бюджет токенов (замерено)

| Момент | Что попадает в контекст | Максимум |
|---|---|---|
| Старт сессии | `STATE.md` (≤ 40 строк) + 5 строк индекса | ~3,3 КБ ≈ 800 токенов |
| Запись | сама запись (≤ 20 строк) + строка подтверждения | ≈ 150–300 токенов |
| Вспомнить задачу | 3 подходящие записи | ≈ 200–1 000 токенов |
| Инструкция скилла | грузится только когда скилл используется | ~2,4 КБ ≈ 600 токенов |

Для русского текста токенов выходит примерно в 1,5–2 раза больше при том же объёме.

Лимиты меняются переменными окружения: `JOURNAL_STATE_MAX`, `JOURNAL_ENTRY_MAX`, `JOURNAL_INDEX_TAIL`, `JOURNAL_SAVE_MAX_KB`.

## Что хранится

```
<проект>/.journal/
  STATE.md         текущий снимок: цель, сделано, в работе, открытые вопросы, следующие шаги
  INDEX.md         строка на сессию: дата | #теги | итог
  log/2026-11.md   записи сессий, по разделу "## " на каждую
  scripts/ data/   вспомогательные скрипты и небольшие данные (≤ 1 МБ) рядом с проектом
  .gitignore       "*" — журнал остаётся локальным и не попадает в git
```

Сессии без проекта (домашняя папка, временная папка, одноразовые рабочие папки) пишутся в общий `~/journal/` (меняется через `JOURNAL_GLOBAL_DIR`).

## Установка

```
/plugin marketplace add IvanStrazov/claude-journal
/plugin install claude-journal@claude-journal
```

Нужен Python 3.8+ в `PATH` (`python3` или `python`). Работает на macOS, Linux и Windows (через Git Bash, который Claude Code использует на Windows).

## Использование

Обычно ничего делать не нужно:

- При старте сессии Claude видит снимок и последние сессии.
- В конце содержательной работы Claude делает запись и обновляет снимок. Можно попросить и явно: `/journal` или «запиши в журнал».
- Спросите «что мы делали по парсеру?» — Claude выполнит `find parser`.

Команды (их запускает Claude, но можно и вручную): `add`, `state`, `find`, `tags`, `save`, `where` — см. `python scripts/journal.py -h`.

## Сравнение

Если нужна автоматическая запись каждого действия с семантическим поиском, берите полноценную систему памяти, например claude-mem. claude-journal — для тех, кому нужен короткий читаемый журнал под своим контролем и предсказуемый низкий расход контекста.
